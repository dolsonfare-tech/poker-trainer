# Gates & Tests Audit — CheckRaise
**Lane:** Safety-net integrity  
**Date:** 2026-07-25  
**Auditor:** Read-only sweep; all findings cite file:line verified by direct code read or `node` execution.

## Summary

**Verification:** 12 verified · 1 adjusted · 1 struck · 1 unsampled

The safety net is largely sound: invariant rules fire correctly on the happy path (confirmed by running `node scripts/check-invariants.mjs` — 0 errors), all 150 jest tests pass, and the CI pipeline runs every gate CLAUDE.md claims. The biggest gap is that **four of the ten invariant rules have realistic bypass paths that the grep patterns miss** — not exploited today, but any future contributor who writes a `require()` call, uses `Sentry.captureMessage`, or aliases posthog through `window.posthog` will silently evade the rule that was meant to stop them. The second gap is **catastrophically low jest coverage on `db.js` (16.5%) and `VillainGuide.jsx` (35.7%) / `FeedbackPanel.jsx` (33.3%)** — the Supabase data-assembly path and the DisagreeBox submission flow are almost entirely untested. The third gap is three CLAUDE.md repo-structure entries that name files which do not exist on disk.
